Chave da Riot

O Carry lê as suas partidas pela API oficial da Riot. Para isso ele precisa de uma chave, que é grátis e você gera no site da Riot com a sua conta do LoL.

!
Sua chave é só sua. Cole apenas no Carry. Não mande para ninguém, nem em print, mensagem ou Discord.
  1. Abra o site da Riot para desenvolvedores

    Entre em developer.riotgames.com e clique em LOGIN, no canto de cima à direita.

    developer.riotgames.com
    RIOT DEVELOPERLOGIN
  2. Entre com a sua conta Riot

    É a mesma conta do LoL. Se ainda não tem, clique em "Criar conta" nessa tela: é grátis e precisa só de e-mail, usuário e senha.

    auth.riotgames.com
    RIOT GAMES
    Nome de usuário
    Senha
    Entrar
    Criar conta
  3. Aceite os termos (só na primeira vez)

    No primeiro acesso a Riot pede para aceitar os termos de uso da API. Leia e aceite para liberar o painel.

    developer.riotgames.com
    Termos da API
    Li e aceitoAceitar
  4. Gere a sua chave

    No painel (Dashboard), na parte Development API Key, marque "Não sou um robô" e clique em Regenerate API Key.

    developer.riotgames.com/dashboard
    • Dashboard
    • Apps
    • Docs
    Development API Key
    RGAPI-••••••••-••••-••••
    Expira em 24h
    Não sou um robô
    Regenerate API Key
  5. Copie a chave

    Clique no ícone de copiar ao lado da chave. Ela começa com RGAPI-.

    developer.riotgames.com/dashboard
    Development API Key
    RGAPI-••••••••-••••-••••-••••••••••••
    COPIAR
    Chave nova gerada
  6. Cole no Carry

    No Carry, abra Administração > Chaves, cole no campo Riot e clique em Salvar. O app testa a chave na hora.

    Carry · Administração
    Chaves
    Riot
    RGAPI-••••••••-••••-••••
    SalvarChave funcionando

As imagens são ilustrativas: os botões ficam nesses lugares, mas a tela da Riot pode mudar um pouco.

Bom saber

Depois de colar

A chave vence em 24 horas

A chave de desenvolvimento dura 1 dia. Quando o Carry avisar "chave vencida", volte ao passo 4, gere outra e cole de novo.

Deu "chave recusada"?

Confira se copiou a chave inteira, começando em RGAPI-, sem espaço no começo ou no fim. Se a chave tiver vencido, gere outra.

É seguro?

A chave fica só no seu computador. O Carry não tem servidor e usa a chave apenas para falar com a Riot.
